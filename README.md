# depot

Runs a placeholder Depot CI review through the Adversary SDK. Detection rules are intentionally not implemented yet.

## Build

```sh
npm install
npm run build
```

## Run

```sh
adversary run . --repo /path/to/repository
```

## Test

```sh
npm test
```

## Layout

- `adversary.yaml` declares the adversary manifest.
- `src/index.ts` contains the TypeScript SDK entry point and no-op review rule.
- `test/index.test.ts` verifies the empty structured review contract.
- `fixtures/clean` is the repository fixture used by the bootstrap test.
- `dist/index.js` is generated by `npm run build` for the CLI runtime.
